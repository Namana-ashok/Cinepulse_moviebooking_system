# 🎬 CinePulse – Full-Stack Movie Ticket Booking System

CinePulse is a full-stack movie ticket booking web application designed to provide users with a convenient platform to explore movies, select seats, and manage their bookings through an interactive interface.

## ✨ Features

- **User Authentication:** User registration and login with password hashing and JWT-based authentication.
- **Movie Browsing:** Explore available movies through a movie listing interface.
- **Seat Selection:** Interactive seat selection for movie bookings.
- **Booking Management:** Backend APIs for managing movie bookings.
- **Account & Settings:** User account information and account management interface.
- **Watch Party:** Frontend feature for creating a group movie-watching session.
- **Demo Payment:** Payment flow in demo-only mode.

## 🛠️ Technologies Used

**Frontend**
- HTML5
- CSS3
- JavaScript

**Backend**
- Node.js
- Express.js
- REST APIs
- JWT Authentication
- bcrypt

**Database**
- MongoDB
- MongoDB Atlas

## 🎯 Project Objective

To develop a full-stack web application that demonstrates frontend development, backend API integration, database connectivity, user authentication, and interactive movie-booking functionality.

## 👩‍💻 Project Status

Developed as a Web Technology project. Some features use demonstration or frontend-only functionality.
